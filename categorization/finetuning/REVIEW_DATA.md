# วิธีตรวจ synthetic_training_review_160.csv

ชุดนี้เป็น **ข้อความสังเคราะห์ที่ AI ร่างใหม่** 160 ข้อความ หมวดละ 20 ข้อ รวม 8 หมวด
ไม่ใช่ความคิดเห็นของพนักงานจริง และหมวดใน category เป็นเพียงข้อเสนอของ AI

## คอลัมน์

- `id`: รหัสข้อความ คงไว้เพื่อคุยกันและติดตามการแก้ไข
- `feedback`: ข้อความที่ต้องการจัดหมวด แก้ให้อ่านเป็นธรรมชาติได้
- `category`: หมวดที่ AI เสนอ เก็บไว้เทียบ ไม่ใช่เฉลยสุดท้าย
- `group_id`: กลุ่มสถานการณ์เดียวกัน สองข้อความต่อกลุ่ม ห้ามแยกเป็น train กับ test
- `reviewed_category`: คนตรวจใส่รหัสหมวดที่ยืนยันแล้ว แม้เห็นด้วยกับ category ก็ต้องกรอก
- `review_status`: เริ่มต้นเป็น pending เปลี่ยนเป็น approved หลังคนตรวจแล้ว
- `review_notes`: เหตุผลหรือข้อที่ทีมตกลงกัน โดยเฉพาะเมื่อเปลี่ยนหมวด
- `suggested_rationale`: เหตุผลประกอบข้อเสนอจาก AI ไม่ใช่ผลตรวจของคน
- `ambiguity_note`: จุดทับซ้อนที่ควรพิจารณา
- `source`: synthetic_ai_draft เพื่อเก็บที่มาของข้อมูล ห้ามเปลี่ยนเป็นข้อมูลจริง

คอลัมน์ทั้งหมดเป็นข้อความ เปิดด้วย Excel หรือ Google Sheets แล้ว export เป็น CSV UTF-8 ได้
ไฟล์ต้นฉบับใช้ UTF-8 BOM เพื่อช่วยให้ Excel อ่านภาษาไทย

## วิธีตรวจร่วมกัน

1. ให้คนแรกอ่าน feedback แล้วเสนอหมวดด้วยตนเองก่อนดู rationale ถ้าทำได้ เพื่อลดการยึดตามคำตอบ AI
2. ให้คนที่สองตรวจหมวดและข้อที่ทับซ้อน แล้วตกลงเฉลยร่วมกัน
3. กรอก reviewed_category ด้วยรหัสหนึ่งในรายการด้านล่าง
4. กรอก review_notes เมื่อแก้หมวดหรือพบกติกาที่ต้องใช้ซ้ำ
5. เปลี่ยน review_status เป็น approved เฉพาะเมื่อยืนยันแล้ว
6. ถ้ายังตกลงไม่ได้ ให้คง pending อย่ารีบยืนยันเพื่อให้โค้ดรันผ่าน
7. ถ้าข้อใดใช้ไม่ได้ ให้แก้หรือลบแถวนั้น แล้วตรวจจำนวนกลุ่มต่อหมวดอีกครั้ง

## รหัสและขอบเขต

| รหัส | ใช้เมื่อเน้น |
| --- | --- |
| welfare | สิทธิและบริการสวัสดิการ เช่น วันลา ประกัน รถรับส่ง สิทธิครอบครัว |
| compensation | เงินตอบแทนงาน เช่น เงินเดือน โบนัส อัตราโอที คอมมิชชัน |
| management | การตัดสินใจ ความยุติธรรม หรือพฤติกรรมของผู้บังคับบัญชา |
| workload | ปริมาณงาน เวลาที่ใช้ทำงาน กำลังคน กำหนดส่ง เวลาพัก |
| environment | สถานที่ อุปกรณ์ ความปลอดภัย บรรยากาศระหว่างเพื่อนร่วมงาน |
| career | การฝึกทักษะ การประเมินเพื่อพัฒนา เส้นทางเติบโต โอกาสเรียนรู้ |
| communication | ข่าวสาร ช่องทาง ข้อมูลที่ไม่ครบหรือไม่สอดคล้อง และการประสานข้อมูล |
| other | ไม่มีประเด็นเฉพาะในเจ็ดหมวด เช่น ข้ามคำถาม เรื่องส่วนตัว ข้อความไม่เป็นสาระ |

เลือกสิ่งที่ผู้ตอบอยากให้องค์กรดูแลเป็นหลัก ไม่ตัดสินจากคำที่พบเพียงคำเดียว
ตัวอย่าง: ค่าโอทีจ่ายไม่ครบเป็น compensation แต่ทำโอทีจนพักไม่พอเป็น workload
เรื่องการพัฒนาทักษะการสื่อสารเป็น career แต่ประกาศไม่ถึงผู้เกี่ยวข้องเป็น communication
หากสองหมวดสมเหตุสมผลพอกัน ให้ทบทวนกติกาก่อนยืนยัน ไม่จำเป็นต้องเชื่อคำตอบ AI

## กลุ่มประโยคและข้อจำกัด

ไฟล์มี 80 กลุ่มสถานการณ์ กลุ่มละสองข้อความ ร่าง group_id ไว้ให้แล้ว
ทีมควรตรวจเพิ่มว่ามีข้อความที่ใกล้กันมากข้ามกลุ่มหรือไม่ ถ้ามีให้รวม group_id
ถ้าการแก้ข้อความทำให้ความหมายหลักต่างหมวดกัน ให้ทบทวนทั้งคู่และแก้กลุ่มตามเหตุผล
เครื่องมือเตรียมข้อมูลจะหยุดถ้ากลุ่มเดียวกันมีเฉลยต่างหมวด

ตรวจแล้วไม่พบข้อความซ้ำแบบ normalized exact match กับข้อสอบ 105 ข้อหรือตัวอย่าง few-shot เดิม
การตรวจนี้ไม่ยืนยันว่าไม่มีความคล้ายเชิงความหมาย จึงยังต้องให้คนตรวจ

ข้อมูลนี้เหมาะกับเริ่มทดลอง pipeline และผลบนข้อมูลสังเคราะห์
ผลทดสอบจากชุดสังเคราะห์ไม่ยืนยันคุณภาพกับความคิดเห็นพนักงานจริง
หากจะอ้างผลทั่วไป ควรมีชุดทดสอบอิสระจากอีกผู้เขียนหรือข้อมูลจริงที่ได้รับอนุญาต

## หลังตรวจครบ

ใช้ ZIP Colab เวอร์ชันล่าสุด เพราะเพิ่มการตรวจ review_status แล้ว
เครื่องมือเตรียมข้อมูลจะใช้ **reviewed_category** เป็นคำตอบจริง
และปฏิเสธไฟล์ที่ยังมี pending หรือยังไม่ได้กรอกเฉลยยืนยัน
คอลัมน์ review_notes/rationale จะไม่ถูกส่งเป็น input ให้โมเดล

จาก repository root:

```bash
python -m categorization.finetuning.prepare --input categorization/finetuning/synthetic_training_review_160.csv
```

ยังไม่ควรเรียก train จนกว่าจะตรวจครบ และไม่ต้องเปลี่ยนเฉลยเป็น approved ในไฟล์ร่างเพื่อทดสอบโค้ด
